# NearBest

NearBest is a web-based marketplace developed to provide a platform for buying and selling affordable products, including surplus and near-expiry products.

This project was developed collaboratively by Computer Science students at Universitas Sumatera Utara.

## Overview

NearBest provides a marketplace platform with different user roles, including buyers, sellers, and administrators.

The system supports product management, marketplace activities, order management, and communication between users.

## Features

### Buyer
- User registration and login
- Browse products
- View product details
- Browse products by category
- Place orders
- View order information
- Communicate with sellers
- Receive notifications

### Seller
- Seller account management
- Store management
- Product management
- Manage product categories and labels
- Manage incoming orders
- View product expiration information
- Communicate with buyers

### Administrator
- Admin dashboard
- User management
- Product management
- Order management
- Product category management
- Product label management
